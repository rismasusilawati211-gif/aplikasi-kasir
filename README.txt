# QuickKasir Web

Aplikasi kasir sederhana yang bisa langsung dipasang di GitHub Pages.

## Cara menjalankan di GitHub Pages
1. Upload `index.html`, `style.css`, dan `script.js` ke repository.
2. Pastikan `index.html` berada di folder utama (root).
3. Buka Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Klik Save.
7. Tunggu proses deploy, lalu buka link GitHub Pages.

Fitur:
- Daftar produk
- Pencarian produk
- Keranjang belanja
- Tambah/kurang jumlah
- Diskon
- Pembayaran Cash
- Pembayaran Transfer
- Hitung kembalian
- Struk pembelian
- Cetak struk
- Tampilan responsif HP
